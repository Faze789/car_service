# Abu Dhabi Desert Safari Adventures

A Flutter web application for browsing and booking desert safari tour packages in Abu Dhabi. The site features tour package listings, a streamlined booking flow, and contact options, with full support for both English and Arabic languages.

## Features

- Browse desert safari tour packages with detailed descriptions and pricing
- Step-by-step booking flow for reserving tours
- Bilingual support with English and Arabic localization
- Responsive web design for desktop and mobile browsers
- Contact section for inquiries and customer support
- Smooth navigation with go_router

## Tech Stack

| Technology | Purpose |
|---|---|
| Flutter | Cross-platform UI framework (web target) |
| Dart | Programming language |
| go_router | Declarative routing and navigation |
| flutter_localizations | English and Arabic language support |

## Getting Started

### Prerequisites

- Flutter SDK 3.x installed with web support enabled
- Chrome or another modern browser

### Installation

```bash
git clone https://github.com/Faze789/car_service.git
cd car_service
flutter pub get
```

### Development

```bash
flutter run -d chrome
```

### Production Build

```bash
flutter build web
```

The built files will be in the `build/web` directory, ready for deployment to any static hosting provider.
